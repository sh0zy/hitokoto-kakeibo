# ひとこと家計簿

記録が面倒で家計簿が続かない人でも、少ない操作で続けられる家計簿Webアプリです。金額だけ、「ランチ850円」のようなひとことの文章、または音声で記録でき、確認・保存・取り消しは入力画面の中で済みます。

アプリを開く：https://sh0zy.github.io/hitokoto-kakeibo/

- 会員登録・ログイン・APIキー・支払いは不要です。家計データは利用者のブラウザの中（端末ごと）に保存し、サーバーには送信しません。
- 文章の解析とカテゴリの分類は、端末の中の決まった規則と辞書で行います（AI・機械学習は使っていません）。
- 音声入力はブラウザの音声認識を使います。多くのブラウザでは通信が必要で、音声の扱いはブラウザによります。音声そのものはアプリに保存しません。
- レシートの写真の読み取りは、端末の中の OCR で行い、画像は保存しません。読み取った内容は確かめてから登録します。
- 端末どうしの同期はありません。機種変更などには、設定の「完全バックアップを書き出す」で保存したファイルを使ってください。
- スマホでは、ブラウザの「ホーム画面に追加」でアプリのように使え、一度開いた後はオフラインでも記録・履歴・レポートが使えます。

このリポジトリには、公開用のビルド済みファイルだけを置いています。
